# P vs NP Main Attack Lock

Primary framework (locked):

- Sheaf-cohomological obstruction on SAT-instance structure.

One-line falsifiable claim:

- There exists a formally definable instance-level sheaf invariant that separates SAT witness existence from polynomial-time witness construction in a way that cannot be captured by known barrier-limited proof schemas.

Freeze policy:

- Non-primary directions are frozen by default (circuit-only expansion, pure proof-complexity branch, algebraic-only branch, geometric-only branch, logic-only branch).
- A frozen branch may reopen only if:
  - it provides a concrete counterexample to the current primary claim, or
  - it supplies a formal lemma that strictly shortens the current primary critical path.
